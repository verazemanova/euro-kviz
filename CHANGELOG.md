# Changelog

V tomto souboru jsou zaznamenány významné změny jednotlivých verzí projektu Euro kvíz.

## [0.5.0] – 7. srpna 2026

První veřejná verze aplikace.

### Přidáno

- převod částek v eurech na české koruny,
- pevný kurz 1 € = 25 Kč,
- lekce obsahující 6 příkladů,
- náhodné pochvaly Eurky,
- náhodná povzbuzení Eurky,
- ochrana proti opakování stejné pochvaly nebo povzbuzení bezprostředně po sobě,
- tlačítko „Nová lekce“,
- počítání správných odpovědí,
- medaile podle výsledku lekce,
- ukončení lekce a zobrazení výsledku,
- základní dokumentace projektu,
- GitHub repozitář,
- publikace aplikace prostřednictvím GitHub Pages.

### Odměny za výsledek lekce

### Technické změny

- JavaScript je rozdělen do menších samostatných funkcí.
- Je vytvořena obecná funkce pro výběr náhodného textu bez bezprostředního opakování.
- Projekt používá Git pro správu verzí.
- Projekt je zveřejněn na GitHubu.
- Verze 0.5.0 byla vydána jako první veřejný release.
