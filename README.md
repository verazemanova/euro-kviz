# 💶 Euro kvíz

Euro kvíz je webová aplikace pro procvičování převodu eur na české koruny.

Cílem projektu je vytvořit jednoduchou, přehlednou a motivační aplikaci, která pomůže uživatelům pravidelně trénovat převod měn. Součástí aplikace je virtuální průvodkyně Eurka, která uživatele během tréninku motivuje pochvalami a povzbuzením.

## Stav projektu

🚧 Ve vývoji (verze 0.4)

## Aktuální funkce

- převod eur na české koruny,
- šest příkladů v jedné lekci,
- automatické vyhodnocení odpovědí,
- zobrazení výsledku po dokončení lekce,
- spuštění nové lekce bez obnovení stránky,
- náhodné pochvaly Eurky,
- náhodná povzbuzení Eurky,
- zabránění opakování stejné pochvaly a stejného povzbuzení dvakrát po sobě.

## Plánované funkce

- medaile za úspěšnost,
- grafická podoba Eurky,
- tipy během tréninku,
- více obtížností,
- statistiky více lekcí.

## Použité technologie

- HTML5
- CSS3
- JavaScript (ES6)
